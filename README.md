# 게스트북 키오스크

CAR ESPERANTO 전시 게스트북. 카메라가 얼굴을 찾아 24 × 32 점으로 바꾸고, 영수증으로 뽑아 주고, 게스트북 벽에 쌓아요.
사진 원본은 저장하지 않고 점(0과 1)만 남아요. 인터넷 없이 돌아가요.

## 화면 구성

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 키오스크 (위 + 아래) | `kiosk.html?screen=both` | 세로 모니터 한 대. 위는 실시간 픽셀 얼굴, 아래는 안내·카운트다운·번호 |
| 위 화면만 | `kiosk.html?screen=top` | 모니터 두 대일 때 위쪽. 카메라·촬영·저장·인쇄를 맡음 |
| 아래 화면만 | `kiosk.html?screen=bottom` | 모니터 두 대일 때 아래쪽. 위 화면 창과 자동으로 맞춰짐 |
| 게스트북 벽 | `wall.html` | 다녀간 얼굴이 쌓임. 적을 땐 크게, 많아지면 촘촘한 모자이크 |
| 관리 | `index.html` | 설정, 영수증 미리보기·테스트 인쇄, 보관함·백업 |

세로 모니터 1080 × 1920이면 위 화면이 정확히 1080 × 1440 (3:4)으로 꽉 차요.

## 실행 (맥)

1. Google Chrome 설치
2. `start.command` 더블클릭 (처음 한 번은 우클릭 → 열기)
3. 메뉴에서 고르기 → 각 창을 한 번 누르면 전체 화면
4. 키오스크·벽에서 `Esc` 두 번 → 관리 화면

`start.command`는 전시용 크롬 프로필을 따로 써요. 게스트북 데이터는 그 프로필 안에 저장되니 키오스크·벽·관리 화면은 꼭 이 파일로 여세요.
모니터가 여러 대면 파일 맨 위 `KIOSK_POS`, `WALL_POS` 좌표를 바꾸면 돼요.

## 촬영 흐름

대기(1 화면을 보세요) → 얼굴 감지(3 버튼을 누르세요, 빨간 점) → 3·2·1 → 찰칵 → **이름 적기**(영문, 카 에스페란토 보행자 언어로 바로 보임 · 버튼 또는 완료) → 가로 영수증 인쇄 + 번호 → 벽에 크게 떴다가 제자리로.

이름은 도트 그래머 변환기의 보행자 단 글꼴(6 × 8 칸, 5 × 7 픽셀)과 같은 규칙으로 그려요. 쓸 수 있는 글자는 A–Z, 0–9, `. , - ? ! / &`, 띄어쓰기. 한글로 치면 "영문으로 적어 주세요"가 떠요. 45초 동안 손대지 않으면 적은 데까지로 넘어가요.

영수증(가로): 왼쪽 픽셀 얼굴 / 오른쪽 위 이름(보행자 언어) · 가운데 `2026 DEGREE EXHIBITION` · `UX DEGREE` · `CAR ESPERANTO` · 아래 D 날짜 · T 시간 · # 번호. 80mm 용지에서 약 118 × 72 mm.
아무도 없으면 위 화면에서 지난 방문자 얼굴이 점이 바뀌며 하나씩 지나가요.

## 하드웨어

- **버튼**: 엔터(또는 스페이스). USB 아케이드 버튼(키보드 인코더)은 **엔터**로 설정하세요. 이름 적기에서 버튼 = 완료가 돼요. 화면 터치도 됨(설정에서 끌 수 있음).
- **이름 입력**: 키보드를 두거나, 터치 화면이면 아래 화면의 자판을 눌러요.
- **카메라**: 웹캠 아무거나. 세로로 달았다면 설정 → 카메라 회전.
- **프린터**: 감열 영수증 프린터 80mm(576점) 또는 58mm(384점).
  - 맥 시스템 설정에서 **기본 프린터**로 지정, 용지 크기를 롤 용지(80mm)로.
  - `--kiosk-printing` 덕분에 대화상자 없이 바로 나가요.
  - 관리 화면 → 테스트 인쇄로 먼저 확인.

## 설치 순서 추천

1. 관리 화면 → **카메라 확인 모드** (오른쪽 위에 카메라 원본, 빨간 상자 = 얼굴, 파란 상자 = 자르는 범위)
2. 조명·배경 맞추기: 얼굴 앞쪽에서 부드러운 조명, 뒤는 어두운 벽이면 Fotomat처럼 얼굴이 또렷해요
3. 관리 화면 → 픽셀 설정
   - 검은 점 비율: 얼굴 안에서 검게 칠할 비율 (얼굴이 하얗게 날아가면 올리기)
   - 이목구비 강조: 눈·코·입 윤곽 강조
   - 배경 어둡게: 머리·어깨 바깥을 검게
   - 얼굴 크기: 화면 속 얼굴 크기
4. 테스트 인쇄 → 몇 명 찍어 보기 → 벽 확인

## 데이터 · 백업

- 저장 위치: 전시용 크롬 프로필 안 (IndexedDB). 번호, 시각, 점 데이터만.
- 관리 화면 → **백업 파일 받기**: 하루에 한 번 권장. **백업 불러오기**로 다른 컴퓨터로 옮길 수 있음.
- **벽 포스터 PNG**: 쌓인 얼굴 전체를 한 장의 고해상도 이미지로. 전시 끝나고 포스터·도록용.

## 문제 해결

- 아래에 "카메라 …" 오류: 다른 프로그램(줌 등)이 카메라를 쓰고 있지 않은지 확인. 5초마다 다시 시도해요.
- 얼굴을 잘 못 찾음: 조명을 밝게, 또는 설정에서 "얼굴이 보일 때만 촬영"을 끄면 가운데 기준으로 찍어요.
- 인쇄 대화상자가 뜸: 크롬이 이미 켜진 상태에서 열었을 때. 크롬을 모두 끄고 `start.command`로 다시.
- 파일을 그냥 더블클릭해서 열면 카메라·얼굴 인식이 안 돼요 (`http://localhost`로 열어야 함).

## 웹에 올려서 쓰기 (전시 당일 컴퓨터 연결 없이)

기록은 **Supabase**(무료 웹 데이터베이스)에, 화면은 **Netlify**(무료 웹 호스팅)에 둬요. 키오스크 · 벽 · 관리 화면을 아무 기기에서 주소로 열면 같은 기록과 설정을 함께 써요.

1. **Supabase**: supabase.com 가입 → New project → 왼쪽 SQL Editor → `supabase.sql` 내용을 붙여 넣고 Run
2. Project Settings → API 에서 **Project URL** 과 **anon public key** 를 복사 → `config.js` 에 넣기
3. **Netlify**: app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → `https://○○○.netlify.app` 주소가 생김
4. 그 주소 + `/kiosk.html?screen=both` (키오스크), `/wall.html` (벽), `/` (관리)

- 인터넷이 잠깐 끊겨도 찍은 얼굴은 그 기기에 모아 두었다가 다시 연결되면 올려요.
- 벽 화면은 4초마다 새 얼굴을 확인해서, 다른 기기에서 찍혀도 크게 떴다가 쌓여요.
- 설정은 관리 화면에서 바꾸면 15초 안에 다른 기기에도 반영돼요.
- 키오스크 기기에서 크롬을 `--kiosk-printing` 으로 켜야 인쇄 창 없이 바로 나가요.
